# Theme Default Images

V0 includes local SVG default visuals. When no WordPress media image is selected, the theme displays these default visuals instead of text placeholders.

Replace with real images in WordPress admin:

- Home page ACF: `hero_image`
- Page ACF: `banner_image`, `section_images`
- Product ACF: `product_main_image`, `product_gallery`
- Blog: Featured Image

Default files:

- `hero-wool-home.svg`
- `sheepskin-rugs.svg`
- `wool-comforters.svg`
- `wool-dryer-balls.svg`
- `wool-gloves.svg`
- `wool-socks.svg`
- `oem-packaging.svg`
- `factory-preview.svg`
- `quality-control.svg`
- `contact-bg.svg`

Recommended image directions:

- Soft wool comforter / sheepskin home lifestyle hero
- Product category lifestyle photos
- OEM packaging, labels, swatches, and sample details
- Clean production, material preparation, sewing, filling, packing
- Quality inspection, size check, stitching check, final packing
